An Agda denpendency graph generator.

It emits your proof's dependency graph — one node per definition, each coloured by state: defined, postulated, a hole, or a module that failed to check.

Getting a graph

# install once
cabal install exe:agda-deps
# emit an interactive HTML view
agda-deps --format=html --view=module-dag-pods \
          --with-source -i test/ -o out/ test/Test.agda

With no --format, the output is Graphviz DOT; a .html or .json path after -o infers the format.
