agda-deps

An Agda denpendency graph generator.

It emits your proof's dependency graph — one node per definition, each coloured by state: defined, postulated, a hole, or a module that failed to check.

Getting a graph

# install once
cabal install exe:agda-deps
# emit the JSON graph
agda-deps --format=json -i test/ -o out/ test/Test.agda
# render it as an interactive page
agda-plotter --view=module-dag-pods -o out/

With no --format, the output is Graphviz DOT; a .json or .dot path after -o infers the format.

The four states

DDefined
Function, datatype, record, constructor — elaborated normally.
PPostulate
An axiom / postulate. A type-level promise, no body.
HHole
Contains an unsolved meta (a ? in source).
FFailed
Module whose type-check failed under --keep-going.

Two outputs

DOT
A .dot graph you can pipe into Graphviz (dot -Tsvg) or any DOT-aware tool. The default format.
JSON
A stable artifact for downstream tooling: packed (base64 CSR) or expanded (arrays of records) — a versioned wire contract consumers can pin to.

Flags worth knowing

--keep-going
Survive type-check errors; the failing module is tagged F.
--skip-agda
Module-level graph straight from a source scan — no elaboration, milliseconds at any scale.
--lazy
Split the JSON into a module skeleton plus per-module detail files, so 100k-node projects stay responsive.
--no-externals
Drop everything outside the project root — stdlib and all — from the graph.
--resolve-deps
Pin Agda's search path to the .agda-lib depend: closure.
--with-term-hashes
Emit a canonicalised Word64 fingerprint per definition subterm into the JSON.
--theme / --config
Colour presets and a kebab-case YAML mirror of every CLI flag.

What reads the graph

The JSON is the product. These read it, and neither links Agda — so both build in minutes.

agda-plotter ↗Renders the graph as an interactive HTML page — 14 views, from module DAGs to definition-level browsing. --lazy keeps the page small on very large corpora. agda-graph-explorer ↗Unused-import and dead-code analysis, 18 graph-level analyses, and an MCP server that answers point queries for coding agents.
